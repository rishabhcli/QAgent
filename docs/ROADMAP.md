# Roadmap

## v0.2 Beta

- Local SQLite engine with durable events, artifacts, leases, cancellation, and restart recovery
- Electron desktop, CLI, and MCP sharing contracts and engine behavior
- Local Chrome-compatible browser path and managed Chromium installation
- Validated model adapters without runtime doubles or silent fallback
- Isolated Git worktrees and GitHub publication policy
- Static documentation, open-source governance, and cross-platform packaging automation

## After Beta Validation

- Certify additional Git hosting publishers through a conformance suite
- Expand deterministic DOM and network browser assertions
- Add stable signed update channels for supported packages
- Publish an adapter SDK and conformance kit
- Improve retention controls, redacted support bundles, and recovery diagnostics

## Not A v0.2 Goal

QAgent does not provide a hosted multi-user dashboard, benchmark corpus, mandatory cloud control plane,
or compatibility layer for v0.1 operational APIs.
