# Governance

QAgent is maintained in public under AGPL-3.0. Contributions use Developer Certificate of Origin
sign-off and the repository Code of Conduct.

Routine fixes and documentation use normal pull-request review. Changes to contracts, migrations,
workspace trust, security boundaries, credential handling, desktop IPC, publication policy, or
automatic merge require an architecture decision record and maintainer approval.

Release status is evidence-based. An adapter is not labeled end-to-end verified without a repeatable,
credential-backed workflow. A draft, local branch, package build, or accepted provider request is not
described as published, merged, released, or externally verified.

Maintainers publish changelogs, checksums, SBOM, provenance, known limitations, and any time-bounded
accepted security risk. Security disclosures follow `SECURITY.md`.
