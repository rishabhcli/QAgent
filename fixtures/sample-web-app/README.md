# QAgent sample web app

This dependency-free counter is QAgent's deterministic repair fixture. It intentionally increments
by two while its grounded test requires an increment of one. Release evidence must be produced from
a temporary Git copy of this fixture; the intentional defect in this directory should remain intact.

Run it with `npm start` and open `http://127.0.0.1:41773`. Run the failing baseline with `npm test`.
